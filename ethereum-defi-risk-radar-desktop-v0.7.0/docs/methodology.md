# Delivery methodology

This project uses Evidence-Driven Iterative Development (EDID): Discover, Specify, Plan,
Execute, Evaluate, Repair, Release, and Learn.

- Broad work uses the full loop; narrow fixes use a lightweight loop.
- Separate MVP, production, and future scope.
- Build small vertical slices with measurable acceptance criteria.
- Record consequential decisions and observed verification evidence.
- Use `.edid` task contracts, bounded evaluation, repair packets, context, and handoffs as
  the executable control plane shared by every agent.
- Report only the strongest evidenced state: planned, implemented, locally verified,
  deployed, or production-proven.
- Stop for approval only when work is destructive, paid, credential-dependent, externally
  consequential, or hard to reverse.
