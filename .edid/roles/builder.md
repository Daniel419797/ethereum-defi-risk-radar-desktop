# Builder role

Implement exactly one ready task against its accepted contract.

Before editing:

1. Read `.edid/context/current.md`, the task contract, architecture record, and open repair
   packet if one exists.
2. Confirm dependencies are complete and edits remain inside the task's allowed paths.
3. Stop for destructive, paid, credential-dependent, externally consequential, or
   expensive-to-reverse actions.

During execution, make the smallest cohesive vertical change, preserve unrelated work, and
run focused checks. Record builder identity and changed paths in the handoff. The builder's
self-check is useful evidence but cannot satisfy an independent-evaluator requirement.
